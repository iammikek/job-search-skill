# Company note

Create this the first time a seat is scored, or the first time a send is logged, whichever comes first. Path: `docs/case-studies/<slug>/README.md`. The slug is the company name in lowercase, with hyphens.

If the file exists, update it. Do not start a second file for the same company. Append the log. Do not rewrite an old log line.

Add a row to `docs/case-studies/README.md` when the company is new.

Do not invent pay, a date, or a message. Do not turn the note into a sales pitch. Do not look up the legal entity or filed accounts unless the owner asks.
