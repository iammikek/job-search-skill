# Rubric wizard

Use this when the owner asks to set up the rubric, or when `docs/job-search/INDEX.md` is missing.

Write the answers only into the private book: `docs/job-search/INDEX.md` and `docs/job-search/scoring-rubric.md`. Do not write them into this skill repo. Do not invent a number, a stack, a place, or an employer.

If the book already exists, read it and ask which lines to change. Do not replace a line the owner left alone.

Ask one group, then wait. Before the first question, show [rubric-example.md](rubric-example.md) so the owner can see the shape. The example is not a default. Copy the templates from this folder on the first run, then fill the blanks from the answers.

## 1. Cash

- Weekly pass floor.
- Figure to negotiate toward.
- Band to accept faster, when place and tenure are clear.
- Whether contract work is in the hunt. If it is: billable days in a year, the perm-equivalent factor, and the shortest term that still counts.

A stated cap under the floor is a hard skip. The floor is not named in an application.

## 2. Work

- Stacks that should score high.
- What remote, local, and a commute mean. Whether a long journey is a lower score or a skip.

## 3. Seat

- The shape to prefer, and the management load that is a hard miss.
- Whether a missing seniority word keeps a seat off the shortlist.

## 4. Fit

- Sectors to prefer.
- Sectors to down-favour.
- Employers to leave off the shortlist.

## 5. Pace

- How many sends are allowed in a Monday week.
- Maximum age of a new posting.
- How long a silent application waits before it is paused.
- Timezone for the week, and the Monday the volume log starts.

## Then write

1. Copy `INDEX.md`, `scoring-rubric.md`, `pipeline.md`, and `volume.md` into `docs/job-search/` if they are not there yet. Copy nothing over a file that already has answers.
2. Fill the index measurements and the rubric bands from the answers. Leave unknown pay as score 3.
3. Show the cash bands, the stacks, the place rule, the shape rule, and the exclude list.
4. Stop. Do not start a weekly pass in the same turn.
